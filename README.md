# Neskart - Online Shopping Platform

React + Vite + Bootstrap project. Products come from https://fakestoreapi.com/

## Run
    npm install
    npm run dev

## Features
- Products and categories fetched from Fake Store API
- Search, category filter, sort
- Product details popup
- Cart with quantity, remove, total (saved in localStorage)
- Registration and login (users saved in localStorage); login required at checkout
- Checkout form and order confirmation
